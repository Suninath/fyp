───────────────────────────────────────────────────────────────────────────

Configuration:
  MOCK_PAYMENTS=true    ← Enable mock payments
  NODE_ENV=development  ← Use development mode

Behavior:
  ✓ All payment API calls are intercepted
  ✓ Mock responses returned instantly
  ✓ Payments marked as SUCCESS automatically
  ✓ No DNS errors, no real API calls
  ✓ Console shows 🎭 emoji when active

When Disabled:
  Set MOCK_PAYMENTS=false to use real payment gateways
  (requires valid credentials)

❓ TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────

DNS Error still occurring?
  → Set MOCK_PAYMENTS=true in .env.local
  → Set NODE_ENV=development
  → Restart backend

Mock not being called?
  → Check backend console for 🎭 emoji
  → Restart backend after env changes
  → Verify MOCK_PAYMENTS=true

Database connection error?
  → Create database: psql -U postgres -c "CREATE DATABASE second_auto_gear_dev;"
  → Or use Docker: docker run --name postgres-dev -e POSTGRES_PASSWORD=password -e POSTGRES_DB=second_auto_gear_dev -p 5432:5432 -d postgres:15

Full troubleshooting:
  → See LOCAL_DEVELOPMENT_GUIDE.md#troubleshooting
  → Or LOCAL_DEVELOPMENT_CHECKLIST.md#common-issues-resolution
